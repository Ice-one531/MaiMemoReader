# 文件清单与用途

按目录逐项说明「这个文件干什么、什么时候会用到、改它会影响什么」。
所有路径都相对于项目根目录 `E:\MaiMemoReader\`。

---

## 根目录

| 文件 | 用途 |
| --- | --- |
| `README.md` | 项目总览：定位、目录结构、快速开始、能力边界。第一次接手先读它。 |
| `AGENTS.md` | 给后续开发者 / Agent 的长期记忆：架构约定、接口硬事实、禁止事项、自检清单、定期维护流程与维护记录。改完涉及接口或结构的改动请更新它。 |
| `.github/workflows/deploy.yml` | GitHub Actions：在 `app/` 下安装 → 类型检查 → 跑测试 → 构建 → 复制 `404.html` → 部署 `app/dist` 到 Pages。 |
| `app/` | 全部可运行代码与前端工程配置，下文按子目录展开。 |
| `docs/` | 五份文档：使用说明、本文件、接口与跨域测试、部署与 PWA、测试记录。 |
| `scripts/` | 与运行无关的辅助脚本（图标生成）。 |

## `app/` 工程配置

| 文件 | 用途 |
| --- | --- |
| `package.json` | 依赖与脚本：`dev` 本地开发、`build` 类型检查 + 生产构建、`preview` 预览产物、`test` 单元测试。 |
| `pnpm-lock.yaml` | 依赖锁定。用 npm 安装时会重新生成 `package-lock.json`，两者等价。 |

| `vite.config.ts` | 构建配置。`base` 默认 `./`，同产物可跑本地也可放 Pages 子路径；`VITE_BASE` 可覆盖。 |
| `vitest.config.ts` | 测试运行器配置：jsdom 环境 + `tests/setup.ts`。 |
| `index.html` | 应用入口。含 `viewport-fit=cover`（iPhone 安全区）、主题色、iOS standalone 元信息、manifest 与图标引用。 |

## `app/src/` 应用源码

### 入口与外壳

| 文件 | 用途 |
| --- | --- |
| `main.tsx` | 挂载 React、包裹 `AppProvider`、生产环境注册 Service Worker。 |
| `App.tsx` | 路由分发、桌面侧栏 / 移动顶栏 / 底部导航、主题与「减少动效」、OIDC 回调处理、首次引导拦截、Toast 容器。 |
| `types.ts` | 全局类型：学习快照、选词方案、文章、题目、作答、任务、设置、导出包。改数据结构先改这里。 |

### `src/api/` 外部接口

| 文件 | 用途 |
| --- | --- |
| `deepseek.ts` | DeepSeek 客户端：SSE 流式解析、JSON 模式、thinking 开关、`/v1/tools/search`、模型价格与费用核算、Key 验证、高峰时段判断。 |
| `maimemo.ts` | 墨墨数据层：统一的 `MaimemoConnector` 接口、`TokenConnector` / `OidcConnector` 两种实现、今日进度与单词拉取、字段映射、中继地址解析、连接测试。 |
| `oidc.ts` | 墨墨官方 OIDC：PKCE 生成（S256）、state/nonce、授权跳转、授权码交换、refresh、撤销、id_token 解析、回调参数读取。 |

### `src/ai/` 生成链路

| 文件 | 用途 |
| --- | --- |
| `prompts.ts` | 四种考试模式的内部策略（篇幅、句法、篇章、推理、题型、干扰项），以及五个阶段模板：智能选词、正文生成、命题、解析补全、质量检查；另有阅读器点词释义与联网检索的查询构造。 |
| `pipeline.ts` | 生成管线：阶段推进、流式回调、逐阶段写库、中断标记、失败不丢已完成结果、质检与解析补全、费用累计；`buildDemoTask` 提供离线演示任务，`previewFromPartial` 从半截 JSON 里抽正文预览。 |
| `validate.ts` | 结构化输出校验：把模型 JSON 收敛为可依赖的数据，剔除选项不足 / 答案越界的题，校验段落数，归一化质检报告。 |
| `demo.ts` | 演示素材：一篇原创英文（386 词，含中文译文与 11 个目标词）+ 4 道题 + 24 个演示单词，供无凭证体验。 |

### `src/lib/` 基础设施

| 文件 | 用途 |
| --- | --- |
| `db.ts` | IndexedDB 封装：九张表（kv / secrets / snapshots / articles / questions / attempts / tasks / glossary / sessions），Promise 化读写。 |
| `vault.ts` | 凭证保险箱：默认内存 + sessionStorage，用户勾选后才写 IndexedDB；提供掩码显示与统一清除。 |
| `settings.ts` | 设置默认值与读写；持久化时把密钥从设置对象里剥离，单独交给 `vault`。 |
| `errors.ts` | 错误解释层：DeepSeek 400/401/402/422/429/5xx、墨墨 401/403/404/429、OIDC 失败、跨域 / 网络、结构解析失败，统一翻译成「标题 + 说明 + 建议 + 是否可重试」。 |
| `text.ts` | 文本处理：分词、词形变化（含不规则表）、目标词形态索引、真实形态定位、句界回溯、evidence 定位、字数与阅读时长。 |
| `format.ts` | 展示格式：金额、时长、相对时间、问候语、百分比、选项字母。 |
| `router.ts` | hash 路由：解析 `#/read/<id>?x=1` 这类地址，`navigate` 支持替换历史记录，避免 Pages 子路径回退问题。 |

## 本地数据存在哪

不在文件系统里，而在浏览器：

- **IndexedDB**（库名 `memo-reader`）：设置、凭证（勾选长期保存时）、学习快照、文章、题目、作答、任务、点词释义缓存；
- **sessionStorage**：当前会话的密钥副本、OIDC PKCE 中间态；
- **localStorage**：OIDC 令牌（按 `sub` 分账号）；
- **Cache Storage**：仅 Service Worker 的静态资源缓存。

「设置 → 数据与存储 → 清除本机数据」会清空前两类与 IndexedDB 全部表；卸载 PWA 时系统也会一并清除。
