## 四、接口连通性与跨域（真实执行）

用 curl 直接观察响应头与状态码，命令与结论详见 `03-接口调研与跨域测试.md`。摘要：

| 探测 | 结果 | 判定 |
| --- | --- | --- |
| `OPTIONS` 墨墨 `get_study_progress`（任意 Origin） | 204 + `access-control-allow-origin` 回显 + 允许 `Authorization, Content-Type` | 预检放行 |
| `POST` 同接口（无效 Token） | 401，**无** `access-control-allow-origin` | 浏览器读不到错误 → 文案不能断言原因 |
| `GET` 墨墨 404 路径 | 404，**无** `access-control-allow-origin` | 同上 |
| `OPTIONS` 墨墨 `/oidc/token` | 204 + ACAO | 公开客户端 PKCE 可行 |
| `POST` 墨墨 `/oidc/token`（缺 code） | 401 + ACAO + `expose-headers: WWW-Authenticate` | 错误可读 |
| `OPTIONS` DeepSeek `/chat/completions` | 200 + ACAO + 允许 authorization | 可直连 |
| `POST` DeepSeek `/chat/completions`（无效 Key） | 401 + ACAO + 可读的 `authentication_error` | 错误可读，能准确翻译 |

## 七、已修复的问题（开发过程记录）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 写入 `E:\` 报 `EISDIR` | E: 是 exFAT，不支持硬链接，而写文件工具用硬链接落盘 | 在 NTFS 工作区开发，最后整体复制到 E: |
| `pnpm install` 提示 esbuild 构建脚本被忽略 | pnpm 10+ 默认拦截 postinstall | 加 `pnpm-workspace.yaml: onlyBuiltDependencies: [esbuild]`；实测即使被拦，vite build 仍正常 |
| 用 PowerShell 改写含中文的 `.ts` 后文件乱码 | PS 5.1 默认按 ANSI 解码 | 改用编辑工具重写该文件；此后不再用 shell 改源码 |
| 页面测试报「找不到这篇文章」 | 用固定 120ms sleep 赌异步时序 | 改为 `waitFor` 轮询，最多 3s |
| 测试断言「第一个高亮词是 sustain」失败 | 文中先出现的是 cumulative | 断言改为匹配词性标记，而非具体单词 |
| 减少动效的 CSS 块语法无效 | 把 `@media` 混进了选择器列表 | 拆成两条独立规则 |
