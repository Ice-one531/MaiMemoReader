# 使用说明

这份文档写给「只想用它背单词」的人。安装、连接、生成、阅读、做题、恢复、备份，一条线走完。

---

## 一、安装成 App（推荐）

### iPhone / iPad

1. 用 **Safari** 打开部署好的网址（`https://<你的用户名>.github.io/<仓库名>/`）。
2. 点底部的「分享」按钮 → 「添加到主屏幕」→ 添加。
3. 之后从主屏幕图标进入，就是没有地址栏的独立窗口，支持离线打开已保存的文章。

> 必须用 Safari 添加；微信内置浏览器、Chrome for iOS 添加的主屏幕图标拿不到完整的 PWA 能力。

### Windows

1. 用 Chrome 或 Edge 打开同一个网址。
2. 地址栏右侧会出现安装图标，或菜单 → 「应用」→ 「安装此站点为应用」。
3. 安装后从开始菜单启动，窗口独立，支持 `Ctrl + 滚轮` 缩放。

### 第一次打开会看到三步引导

- 想先体验：点「用演示数据开始」，全部功能可用，不消耗任何 API。
- 想马上用真数据：点「去配置账号」，按下一节填凭证。

## 二、连接墨墨背单词（二选一）

到「设置 → 墨墨背单词」。

### 方式 A：个人 Token（最快）

1. 打开墨墨 App → 我的 → 更多设置 → 实验功能 → 开放 API，复制 Token；
   或电脑打开 <https://open.maimemo.com/open/api/v1/tokens/openapi> 获取。
2. 粘贴到「个人 API Token」，保持「在本机长期保存」勾选（默认开）。
3. 点「连接测试」。看到「连接正常 · 今日进度 x/y」就成功了。
4. 回到「今日」页，点「同步今日」，把当天单词拉下来。

> 显示「请求没有到达墨墨，或被跨域策略拦下」时：先确认 Token 没复制错；仍然失败就配置下一节的中继。

### 方式 B：官方授权登录（需要审核）

1. 到 <https://open.maimemo.com/app> 创建应用：
   - 应用类型选 **纯前端应用**（走 PKCE，不需要 client_secret）；
   - 主页 URL 与登录回调地址使用同一个域名（就是你部署的 Pages 域名）；
   - 权限只勾选「只读学习数据」相关项。
2. 审核通过后，把 `client_id` 填到设置页，scope 保持默认 `openid profile`（若有额外只读权限，按审核结果追加）。
3. 点「开始墨墨授权登录」，在墨墨官方页面同意授权，会自动回到本站并切换到该账号。
4. 令牌默认 1 小时过期，自动用 refresh_token 续期；续期失败会提示重新授权。

两种方式共用同一份数据读取层，切换不会影响已生成的文章。

### 可选：中继（只在直连失败时用）

浏览器直连墨墨有一个现实问题：**错误响应不带 CORS 头**，所以 Token 错了在浏览器里也只表现为"网络错误"。如果你需要准确的错误码，或所在网络访问不了 `open.maimemo.com`，部署一个最小的 Cloudflare Worker 中继：

```bash
cd app
npm i -g wrangler
wrangler deploy worker/maimemo-relay.js --name memo-relay
```

然后在设置页填写 `https://memo-relay.<你的账号>.workers.dev`。中继只转发 `/api/v1/memo/**` 只读接口，透传 Authorization，不解析、不记录、不缓存，也不是任意 URL 代理。

## 三、连接 DeepSeek

到「设置 → DeepSeek」。

1. 在 <https://platform.deepseek.com/api_keys> 创建 Key，粘贴进来。
2. 点「验证 Key」。看到「连接正常，浏览器可直连 DeepSeek」即可。
3. 是否长期保存：
   - 不勾选：Key 只在当前会话（刷新页面后需要重填）；
   - 勾选：写入本机 IndexedDB，换设备不会同步。
4. 模型选择：
   - `deepseek-flash`：默认，快且便宜，日常精读够用；
   - `deepseek-v4-pro`：长文与命题更稳，成本约为前者 4.5 倍。
5. 「深度思考」默认关闭。关闭时可用 temperature 控制文风；开启后模型先推理再写作，更慢更贵。
6. 「联网检索」默认关闭。开启后会用官方 Search 工具查公开的真题话题与行文风格（按次计费），结果只作为风格参考，不复制原文。

页面会显示当前是高峰还是空闲时段，并给出本次生成的大致费用区间。

## 四、生成今天的精读

1. 「今日」页确认已同步到单词（没有就点「同步今日」或「用演示数据」）。
2. 点「生成今日精读」。
3. 选考试模式（四种模式的句法、篇章、题型、干扰项策略各不相同，不是只改字数）。
4. 其他可选：
   - 题材：留空让 AI 从单词里找主题；
   - 篇幅：短文 / 标准 / 长文；
   - 难度 1–5；
   - 题目数量：3–6；
   - 组篇：单篇（默认）或自动组篇（AI 判断是否拆成 2–3 篇）；
   - 接续今天的会话：让新文章避开今天已用过的主题与词。
5. 点「开始生成」。

生成过程中会依次经过：读取学习数据 → AI 智能选词 → 构思与正文 → 命题 → 质量检查 → 存入书架。进度条按阶段推进，正文阶段会显示已写内容的实时预览；文案会随机换，不占用额外请求。

> 在这期间**尽量让页面留在前台**。iOS 切到微信再回来，网络请求可能已经被系统掐断——回来点「继续」即可，已完成的阶段不会重做，也不会重复扣费。

生成完成后自动进入阅读器。

## 五、精读

- **点任意单词**：底部弹出释义。目标词直接显示文中语境义；其他词可以先查本地缓存，没有缓存时点「让 AI 解释」现生成（一次约 ¥0.0006，之后本地缓存复用）。
- **译文**：右上角「译文」开关，按段对照显示，不打断英文排版。
- **词汇**：「词汇 x/y」展开覆盖分析：这一篇实际用到了多少个目标词、每个词在文中的形态，以及 AI 为什么选这些词、放弃了哪些词。
- **专注**：隐藏工具栏干扰，阅读进度条仍在顶部。
- **收藏 / 导出**：收藏进入书架；导出为 Markdown（含译文与词表），可以直接贴进笔记软件。
- **规划多篇时**：文末会出现「继续生成规划中的第 N 篇」，按需点，不会自动多花钱。

## 六、阅读理解

1. 阅读器底部点「开始阅读理解」。
2. 逐题点选，底部显示已答数量；需要回看原文时点「展开原文」。
3. 全部作答后点「交卷」。**交卷前不会显示任何答案。**
4. 成绩页给出分数、逐题对错、你的选择与正确答案、中文解析，以及高亮的**原文依据**（会定位到具体段落）。
5. 可以「重新练习」；历史作答记录保留在本机，书架会显示最佳正确率。

## 七、生成中断了怎么办

- **切后台 / 锁屏 / 关掉页面**：重新打开时首页顶部会出现「有一篇没写完的精读」，点「继续」。
- **正文已完成、命题没完成**：只会重跑命题阶段。
- **正文请求已断开**：保留已选好的词，你可以手动重新生成正文，不会自动重发。
- **想放弃**：在生成页点「停止生成」，已完成的阶段仍会保存，可之后继续。

恢复的是**已完成的工作阶段**，不是强行恢复已经断开的模型推理——这是刻意的设计，避免为了"看起来能后台运行"而引入队列和服务器。

## 八、数据、备份与隐私

「设置 → 数据与存储」：

- **导出全部数据**：一个 JSON 文件，含文章、题目、作答记录、学习快照、任务状态与偏好设置。**不含 DeepSeek Key 与墨墨 Token。**
- **导入**：合并到当前设备（同名记录覆盖）。
- **清除本机数据**：删除文章、题目、记录、凭证、未完成任务，不可撤销。
- **存储用量**：显示 IndexedDB 的占用与浏览器配额。

隐私边界：

- 没有后端，没有账号体系，没有埋点；
- 学习数据只从墨墨读，不写回；
- 生成内容只经过你自己的 DeepSeek Key；
- Service Worker 只缓存应用静态资源，任何带 Authorization 的请求都不缓存。

## 九、常见问题

**Q：今日页说「今天的学习数据还没到」。**
A：墨墨接口没有日期参数，只返回"今天"。请先在墨墨 App 里打开学习、确认开启了自动同步，再点「同步今日」。仍为空就检查 Token 是否过期。

**Q：连接测试失败，但 Token 应该是对的。**
A：浏览器直连墨墨在错误响应上拿不到跨域头，所以前端无法区分「Token 错」和「CORS 拦下」。先换网络试；仍不行就配中继再测，中继会把真实状态码透出来。

**Q：生成到一半卡住了。**
A：正文阶段模型在长句里换气，偶尔确实慢。超过 4 分钟无响应会自动超时并保留已选词，点「继续」重跑正文即可。

**Q：为什么只生成一篇，明明词分成了几个主题？**
A：AI 组篇只是建议。默认只生成第一篇以控制成本，文末有「继续生成第 N 篇」按钮。

**Q：费用显示 ¥0.03，账单却不一样？**
A：页面金额 = 官方价格表 × 接口返回的 usage，并按时段（高峰 / 空闲）估算；法定节假日无法在前端判断，缓存命中比例也可能与估算不同。以 DeepSeek 账单为准。

**Q：换手机了，文章能同步吗？**
A：不能，这是刻意的本地优先设计。用「导出 / 导入」迁移即可。

**Q：能导入到墨墨、或修改我的学习记录吗？**
A：不能。本项目只申请只读学习数据权限，不做写入。
