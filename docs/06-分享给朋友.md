# 给朋友：三分钟用上 MaiMemo Reader

这是一个**纯前端**的英语精读小站：读你在墨墨背单词当天的学习数据，让 DeepSeek 挑词、写成四六级/考研风格的原创英文，再配阅读题和原文依据。
没有服务器、没有账号系统，你自己的墨墨 Token 和 DeepSeek Key 只存在你自己的手机/电脑里。

---

## 先选一条路

| 你的情况 | 走哪条 |
| --- | --- |
| 只想用，不想碰代码 | **A. 用朋友给你的网址**（他部署好之后发链接给你） |
| 想自己部署一份 | **B. 拖一个文件夹到 Netlify**（不用装任何软件） |
| 想改代码 / 本地跑 | **C. 装 Node 跑源码** |

---

## A. 用现成的网址（最省事）

1. 用 **Safari**（iPhone）或 **Chrome/Edge**（Windows）打开朋友给的链接。
2. 第一次会让你选：**用演示数据开始** 或 **去配置账号**。
3. 想用真实数据，去「设置」填两样东西：

   - **墨墨个人 Token**：墨墨 App → 我的 → 更多设置 → 实验功能 → 开放 API，复制那串字符粘进去，点「连接测试」。
   - **DeepSeek API Key**：platform.deepseek.com → API keys → 创建，粘进去，点「验证 Key」。
     （费用从你自己的账户扣，一次生成通常几分钱。）

4. 回到「今日」→「同步今日」→「生成今日精读」。
5. iPhone 想当 App 用：Safari 分享按钮 → **添加到主屏幕**。Windows：地址栏右侧安装图标。

> 不想填任何 Key？直接点「用演示数据开始」，读文章、点词、做题、看解析全都能体验，只是文章是固定的那一篇。

## B. 自己部署（不用装软件）

1. 解压 `MaiMemoReader-静态版.zip`，得到一个含 `index.html` 的文件夹。
2. 打开 <https://app.netlify.com/drop>，把**整个文件夹**拖进去。
3. 等十几秒，得到一个 `https://xxx.netlify.app` 的网址，这就是你的站点。
   （Cloudflare Pages 的「Direct Upload」同样可以。）
4. 手机/电脑打开这个网址，按上面 A 的第 3 步填自己的凭证即可。

这个包是已经构建好的静态文件，**不含任何密钥**。想更新版本就重新拖一次。

## C. 本地跑源码

需要 Node 20+。

```bash
cd MaiMemoReader/app
npm install
npm run dev        # 打开 http://localhost:5173
```

想部署到自己的 GitHub Pages：

```bash
cd MaiMemoReader
git init && git add . && git commit -m "init"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

然后仓库 Settings → Pages → Source 选 **GitHub Actions**。工作流会自动构建并发布，网址是 `https://<用户名>.github.io/<仓库名>/`。
（工作流里的 `VITE_BASE` 已按仓库名自动拼好，用户页才需要改成 `/`。）

## 常见问题

**Q：我的 Token 会不会被朋友看到？**
不会。凭证存在你自己浏览器的 IndexedDB / sessionStorage 里，导出数据时也会被剔除。别人打开同一个网址看到的是空书架。

**Q：必须用墨墨吗？**
生成真实文章需要当天有学习数据。没有墨墨账号就只能用演示数据。目前没有"手动输入单词"的入口。

**Q：一天能生成几篇？会不会很贵？**
按需点。默认一次完整生成是 4 次模型调用：`deepseek-flash` 通常 ¥0.05 以内，`deepseek-v4-pro` 约 ¥0.2。页面会显示本次估算。

**Q：切到微信再回来，生成断了怎么办？**
回首页会有「有一篇没写完的精读」，点继续只会重跑没完成的阶段，不会重复扣费。

**Q：换设备了，文章能同步吗？**
不同步，这是刻意的本地优先设计。用「设置 → 数据与存储 → 导出」再「导入」。

**Q：手机上显示"请求没有到达墨墨"？**
浏览器直连墨墨时，Token 错误和跨域失败在表现上是一样的。先确认 Token 没复制错、换网络试试；仍不行就让部署的人配一下 Worker 中继（见 `docs/04-部署与PWA安装.md` 第五节）。

## 给部署者的一句话

你不需要替朋友保管任何 Key。他要自己去 open.maimemo.com 拿 Token、去 platform.deepseek.com 拿 Key。
你要做的只有：把站点部署好，把链接发给他，告诉他点「添加到主屏幕」。
